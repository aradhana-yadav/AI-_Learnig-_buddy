# AI Learning Buddy

## Project Overview
AI Learning Buddy is a Streamlit-based web application that helps users learn any topic interactively.

## Features
- Explain Concept
- Real-Life Example
- Generate Quiz
- Ask Anything

## Technologies Used
- Python
- Streamlit

## How to Run
1. Install Streamlit
2. Run:
   streamlit run app.py
